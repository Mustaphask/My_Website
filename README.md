# Mustafa Skaiki — Personal Brand / Consulting Site

Premium one-page consulting-style site. Black & white only, high-end typography, big whitespace. Built with Next.js (App Router), TypeScript, Tailwind, shadcn/ui, framer-motion, lucide-react, recharts, next-themes.

## Install & run

```bash
npm install
# or explicitly:
npm i framer-motion next-themes recharts lucide-react

npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Configuration

- **CV:** Place `Mustafa-Skaiki-CV.pdf` in `public/` (Download CV button).
- **Calendly:** Set `profile.calendlyUrl` in `lib/data.ts`.
- **Contact form:** Set `profile.formActionUrl` in `lib/data.ts` to your Formspree endpoint (e.g. `https://formspree.io/f/xxxxxxxx`).
- **Favicon:** Add `public/favicon.ico` if desired.

## Tech stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- shadcn/ui (Button, Card, Input, Textarea, Label)
- framer-motion
- lucide-react (monochrome)
- recharts (skills bar chart)
- next-themes (dark mode)

No backend or database. Contact: mailto, WhatsApp (wa.me), LinkedIn, optional Formspree form.
